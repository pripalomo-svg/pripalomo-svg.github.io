Conexão com o site

Publicação com um clique

Para o botão Publicar no site funcionar, cole aqui (uma única vez) o seu código de acesso do GitHub. Ele fica guardado só neste navegador. Sem o código, use o botão Baixar projetos.json e suba o arquivo manualmente no GitHub.

✓ Código salvo neste navegador. Remover

Como criar o código de acesso (passo a passo, faz uma vez só)
  1. Entre no GitHub e abra github.com/settings/personal-access-tokens/new.
  2. Em Token name, escreva: Painel do site. Em Expiration, escolha 1 ano.
  3. Em Repository access, marque Only select repositories e escolha pripalomo-svg.github.io.
  4. Em Permissions → Repository permissions, encontre Contents e mude para Read and write.
  5. Clique em Generate token, copie o código gerado e cole no campo acima.
